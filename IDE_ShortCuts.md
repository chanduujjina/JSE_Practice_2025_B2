## Shortcuts in IDE
- To open a java file inside project -> CTR+SHIFT+R

- To open file outside project(jar/jdk) -> CTR+SHIFT+T

- To open a method inside a class -> CTR+O
- assign variable for non void method call -> CTR+1

## Debugging shortcuts
- Move to next line -> F6
- Move into the method -> F5
- Move to next debug point -> F8
